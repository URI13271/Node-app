## 도보 경로 (2026-11-11 보행망 기준으로 다시 만듦)

## 현장 조사 체크리스트

1. 장소마다 실제 출입구 위치와 정문 여부 (스마트폰 GPS로 좌표 기록, 사진 1장). 특히 위에서 옮긴 2곳
2. **표시 없는 차도 횡단 지점**: 35.152795, 128.099881 (도서관 동쪽 광장 남쪽 끝 → 교양학관 쪽). 횡단보도가 있으면 `osm/manual_crossings.json`에 양 끝 좌표를 적는다. 없으면 이 경로를 쓸지 정한다
3. **도서관 앞 큰길 횡단보도**: 도서관 북쪽 큰길(동서 방향)에 OSM상 횡단보도가 도서관 동쪽 1곳뿐이다. 도서관 정면이나 학생회관 앞에 횡단보도가 있으면 위치를 기록한다 (학생회관 2순위 경로 506m가 크게 줄어듦)
4. **인도 유무**: 경로가 지나는 길에 인도가 실제로 있는지, 주차장에서 인도로 나가는 길이 막혀 있지 않은지 (울타리, 화단, 공사)
5. 계단 위치와 경사 (도서관 북쪽 주차장 남쪽의 짧은 계단 2곳), 휠체어, 유모차로 갈 수 있는지
6. 단계 문장에 쓸 눈에 띄는 대상 (간판, 조형물, 계단)
7. 건물 3동과 도착 방향에서 보이는 주변 건물의 층수
8. 주차장 면수, 유료 여부, 출입 제한 시간

조사 뒤에는 `entrances.geojson`, `osm/manual_crossings.json`을 고치고 `python -m scripts.build_walk_routes`로 경로를 다시 만든 다음, 단계 문장을 새 선에 맞춰 고치고 `python -m scripts.load_seed`로 적재한다.
