## osm_context_gnu.json 형식

크기를 줄이려고 좌표를 원점 `o`에서의 `u`도(1e-5도, 약 1m) 단위 정수로 저장했다.

```
{
  "o": [128.09, 35.14],      원점 [경도, 위도]
  "u": 0.00001,              단위
  "buildings": [[x1, y1, x2, y2, ...], ...],   건물 바닥 (다각형 1개 = 배열 1개)
  "green":     [[...], ...],                   녹지 (다각형)
  "water":     [[...], ...],                   물 (다각형)
  "roads":     [[등급, x1, y1, x2, y2, ...], ...],  도로 (선). 첫 값 등급: 2 간선, 1 동네 길, 0 단지 안 길
  "paths":     [[x1, y1, ...], ...]            보행로 (선)
}
```

실제 좌표 = `[o[0] + x * u, o[1] + y * u]` (소수점 6자리로 반올림). 푸는 함수는 `js/map.js` 의 `loadCampusContext()`.

- 출처: OpenFreeMap 벡터 타일(z14, 2026-11-01 판). 데이터 © OpenMapTiles © OpenStreetMap contributors (ODbL). 지도에 출처 표기 필수.
- 시연 장소가 바뀌면 같은 출처에서 도로, 보행로, 건물 바닥, 녹지, 물을 뽑아 위 형식으로 다시 만든다.
