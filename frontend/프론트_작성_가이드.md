# 프론트엔드 작성 가이드 (majunggil/frontend)

화면 4개(검색, 장소 상세, 3D 안내, 관리자)와 공용 모듈의 `todo()`, `TODO` 를 실제 코드로 바꿀 때 지키는 규칙과 순서를 정리한 문서다.
빌드 도구 없이 HTML + CSS + 바닐라 JavaScript(ES 모듈)로 만든다. React, npm 패키지를 추가하지 않는다.
API 응답 형식은 `../../doc/요구사항/API 명세서_v1.3.md`, 화면 구성 기준은 `../docs/screens/*.png` 를 본다.

## 1. 실행과 mock

```bash
cd majunggil/backend
uvicorn app.main:app --reload --port 8000
```

- http://localhost:8000 으로 연다. 파일을 고치면 새로고침(F5)만 하면 된다.
- HTML 을 더블클릭(`file://`)해서 열지 않는다. ES 모듈과 API 호출이 막힌다.
- 백엔드 API 가 아직 501 이면 `http://localhost:8000/?mock=1` 로 연다. 같은 탭에서는 계속 유지되고 `?mock=0` 으로 끈다.
- mock 으로 401, 409, 429, 404 를 흉내 내는 방법은 `mock/README.md` 에 있다.
- 휴대폰에서 위치 기능을 시험할 때는 HTTPS 가 필요하다. `../README.md` "휴대폰에서 시험하기" (cloudflared 임시 터널)를 따른다.

```

```

- 공용 모듈은 `pages/` 를 import 하지 않는다.

## 4. 화면 JS 기본 틀

모든 화면 JS 는 같은 모양으로 쓴다. 읽는 사람이 어느 화면이든 같은 자리에서 같은 것을 찾을 수 있게 하기 위해서다.

```js
// place.html?id=1 (F-01 상세 ...)
import { getPlace } from '../api.js'
import { $, param, toast, escapeHtml } from '../util.js'

// 1. 주소 값, 요소, 화면 상태
const placeId = Number(param('id'))
const state = { place: null, routes: [] }

// 2. 그리기: state 만 보고 DOM 을 바꾼다 (서버 호출 금지)
function render() { ... }

// 3. 불러오기: 서버 호출 → state 갱신 → render()
async function load() { ... }

// 4. 이벤트 연결
function bind() { ... }

// 5. 시작
bind()
load()
```

| 규칙 | 이유 |
|---|---|
| `render()` 안에서 `await` 하지 않는다 | 그리기와 불러오기를 섞으면 순서 문제가 생긴다 |
| 화면 상태는 `state` 객체 하나에 모은다 | 어떤 값이 화면을 바꾸는지 한곳에서 보인다 |
| 주소 값은 처음에 한 번 읽는다 | `param('id')` 를 여기저기서 부르지 않는다 |
| 잘못된 주소 값(`id` 없음, 숫자 아님)은 바로 안내하고 멈춘다 | 서버에 `NaN` 을 보내지 않게 |

검색처럼 요청이 겹칠 수 있는 곳은 늦게 도착한 옛 응답을 버린다.

```js
let seq = 0
async function search(q) {
  const my = ++seq
  try {
    const data = await getPlaces(q)
    if (my !== seq) return                       // 더 새 검색이 있으면 버린다
    title.textContent = q ? `검색 결과 ${data.total}곳` : '시연 장소'
    list.innerHTML = data.items.length
      ? data.items.map((p) => `<li><a class="card" href="/place.html?id=${p.id}">${escapeHtml(p.name)}</a></li>`).join('')
      : '<li class="empty">검색 결과가 없습니다.</li>'
  } catch (e) {
    if (my === seq) showLoadError(e)
  }
}
```

## 5. API 호출과 오류 처리 규칙

### 5.1 호출

- `fetch` 를 화면 파일에서 직접 쓰지 않는다. `js/api.js` 의 함수만 부른다. 그래야 mock 과 실제 서버가 같은 코드로 돈다.
- 응답 필드는 서버와 같은 snake_case 그대로 쓴다 (`walk_time_min`, `navigation_target`). camelCase 로 바꾸지 않는다.
- 좌표는 항상 `[경도, 위도]` 배열이다 (`location.coordinates`).
- 필요한 API 가 `api.js` 에 없으면 화면에서 만들지 말고 `api.js` 에 함수를 추가한다.
- 한 화면에서 서로 기다릴 필요 없는 요청은 `Promise.all` 로 함께 보낸다.

```js
const [place, buildings, routes] = await Promise.all([getPlace(id), getBuildings(id), getWalkRoutes(id)])
```

### 5.2 오류

`api.js` 는 실패하면 `ApiError` 를 던진다. `status` 와 `code` 로 나눠 안내한다.

| 상황 | `status` / `code` | 화면 처리 |
|---|---|---|
| 네트워크 끊김 | `0` / `NETWORK` | "연결을 확인하세요" + 다시 시도 버튼 |
| 입력 오류 | `400` / `INVALID_INPUT` | `details[]` 의 `field` 로 해당 칸 옆에 `message` 표시 |
| 키 틀림 | `401` | 관리자 키 입력으로 되돌림 |
| 없는 장소 | `404` | "찾을 수 없는 장소" + 홈 링크 |
| 버전 충돌 | `409` | 관리자 충돌 비교 창 (6.4) |
| 요청 과다, 키 잠김 | `429` | `retryAfter` 초를 안내. 관리자는 `details[0].reason === 'locked'` 이면 "10분 잠김" |
| 서버 오류 | `500`, `503` | "잠시 후 다시 시도" + `requestId` 를 작게 표시 (문의용) |

- 잡지 못한 오류는 `util.js` 가 알림으로 띄운다. 그래도 화면마다 `try/catch` 로 위 표대로 안내하는 것이 기본이다.
- 오류 메시지를 `alert()` 로 띄우지 않는다. `toast()` 또는 화면 안 안내 칸을 쓴다.

### 5.3 캐시

- 도보 경로는 서버가 `no-cache` + `ETag` 를 보내므로 브라우저가 알아서 재검증한다. JS 에서 `If-None-Match`, 304 를 다루지 않는다.
- 관리자 편집 화면만 `getWalkRoutes(id, null, { fresh: true })` 로 항상 최신본을 받는다.

| `n-1` (마지막 단계) | 모두 주황 | "n / n" | 사용 | "도착" |
| `n` | 모두 주황 | "도착" | 이전/다음 숨김, `#done-actions`(장소 정보, 처음으로) 표시 | |
| 경로 없음, 오류 | 없음 | 비움 | 비활성 | "다음"(비활성) |

- 지나온 구간은 `fractionOnPath(route.path.coordinates, 현재 단계 지점)` 으로 구해 `drawRoute` 에 넘긴다.
- 서버가 단계 카메라를 항상 채워 준다 (`camera_is_default` 가 `true` 면 계산값). 화면에서 카메라를 다시 계산하지 않는다.
- 문장 칸 `#step-text` 에 `aria-live="polite"` 가 있어 단계가 바뀌면 낭독기가 문장만 읽는다 (진행 막대는 `aria-hidden`). 카드 문장은 `textContent` 로 바꾼다.

## 7. 공용 모듈 작성 지침

함수 이름과 인자는 뼈대에 정해져 있다. 바꿔야 하면 부르는 화면을 모두 같이 고치고 PR 설명에 적는다.

### 7.1 `geo.js`

DOM 을 쓰지 않는 순수 함수만 둔다. 좌표는 `[경도, 위도]`, 거리는 미터.

| 함수 | 방법 |
|---|---|
| `distanceM(a, b)` | 하버사인 공식, 지구 반지름 6371008.8m |
| `pathLengthM(path)` | 이웃한 두 점 거리의 합 |
| `nearestVertex(path, p)` | 꼭짓점마다 `distanceM` 해서 가장 작은 번호 |
| `pointAlong(path, t)` | 전체 길이 x t 지점이 들어 있는 구간을 찾아 선형 보간 |
| `fractionOnPath(path, p)` | 각 구간에 p 를 수선으로 내린 가장 가까운 지점까지의 길이 / 전체 길이 |
| `pathUntil(path, t)` | 처음부터 `pointAlong(path, t)` 까지의 점 배열 |

```js
const R = 6371008.8
const rad = (d) => (d * Math.PI) / 180
export function distanceM([lng1, lat1], [lng2, lat2]) {
  const dLat = rad(lat2 - lat1), dLng = rad(lng2 - lng1)
  const h = Math.sin(dLat / 2) ** 2 + Math.cos(rad(lat1)) * Math.cos(rad(lat2)) * Math.sin(dLng / 2) ** 2
  return 2 * R * Math.asin(Math.sqrt(h))
}
```

- 경로 길이가 0 이거나 점이 하나뿐인 경우를 먼저 처리한다 (0 으로 나누기 방지).
- 위치는 서버로 보내지 않는다 (ADR-006). 이 파일의 결과도 서버로 보내지 않는다.

### 7.2 `map.js`

| 함수 | 작성 지침 |
|---|---|
| `createMap(container, view)` | `new maplibregl.Map({container, style: DEFAULT_BASEMAP_URL, ...view})`. 나침반(`NavigationControl`), 출처 표기 켬. `BASEMAP_TIMEOUT_MS` 안에 `load` 가 없거나 배경 지도 타일 오류가 나면 대체 지도로 바꾼다. 지도를 못 만들면(WebGL 없음) `null` 을 돌려주고 안내 문구를 넣는다 |
| `loadCampusContext()` | `CAMPUS_CONTEXT_URL` 을 받아 `data/README.md` 형식대로 푼다. 실제 좌표 = `o + 정수 x u`, 소수 6자리 반올림. 결과는 GeoJSON FeatureCollection 5개 |
| `drawBuildings(map, buildings)` | `fill-extrusion` 레이어. 높이 `['get', 'render_height_m']`, 색은 `is_target` 이면 `cssVar('--target')`, 아니면 `--map-bldg` |
| `drawRoute(map, route, doneFraction)` | 경로 전체 선(`--accent`)과 지나온 구간(`pathUntil`, 흐린 색) 두 레이어. 다시 부르면 소스 데이터만 바꾼다 (`setData`) |
| `drawMarkers(map, place, options)` | `maplibregl.Marker({ element: markerElement(kind, 이름), anchor: 'bottom' })`. 모양은 이미 구현됨: 주차장 = 파란 사각형 + P, 입구 = 초록 마름모 + 문, 랜드마크 = 회색 원. 색만으로 구분하지 않으려고 모양을 함께 쓴다. 범례는 `renderLegend(요소, 종류들)` |
| `flyTo(map, view)` | `map.flyTo({center, bearing, pitch, zoom})`. 사용자가 움직임 줄이기를 켰으면(`prefers-reduced-motion`) `jumpTo` |

- 레이어, 소스 id 는 `lm-` 로 시작한다 (`lm-buildings`, `lm-route`, `lm-route-done`). 배경 지도 오류와 우리 레이어 오류를 이 접두로 구분한다 (`tests/map.test.js` 의 todo).
- 대체 지도로 바꾸면 우리 레이어(`lm-*`)를 다시 그려야 한다. 그리기 함수를 다시 부를 수 있게 마지막 데이터를 기억해 둔다.
- 지도 색은 `cssVar('--...')` 로만 읽는다. 다크 모드에서도 자동으로 맞는다.
- 배경 지도 주소를 바꾸면 `backend/app/frontend.py` 의 CSP 허용 주소도 같이 바꾼다.
- 배경 지도(OpenFreeMap) 이용 조건은 [검증 필요: 시연 전 OpenFreeMap 문서 확인]. 출처 표기(`CONTEXT_ATTRIBUTION`)는 지우지 않는다.
- 계산 부분(좌표 풀기, 대체 지도 전환 판단)은 지도 객체 없이 테스트할 수 있게 별도 함수로 뺀다. 좌표 풀기 형식은 `data/README.md`, 전환 규칙은 `tests/map.test.js` 의 todo 를 따른다.

## 13. 자주 하는 실수

| 실수 | 증상 | 바로잡기 |
|---|---|---|
| HTML 파일을 더블클릭해서 엶 | 모듈 로드 오류, API 실패 | http://localhost:8000 으로 연다 |
| `[위도, 경도]` 순서 | 지도가 엉뚱한 곳 | 항상 `[경도, 위도]` |
| `updated_at` 을 `new Date()` 로 바꿈 | 관리자 저장이 항상 409 | 받은 문자열 그대로 |
| 화면에서 `fetch` 직접 호출 | mock 이 안 먹음, 오류 형식 제각각 | `api.js` 함수 사용 |
| `innerHTML` 에 서버 글자 그대로 | XSS 위험 | `escapeHtml` 또는 `textContent` |
| `onclick="..."` 속성 | CSP 위반 로그 | `addEventListener` |
| 색 값 직접 입력 | 다크 모드에서 안 보임 | `var(--...)`, 지도는 `cssVar()` |
| 같은 대상에 레이어를 매번 새로 추가 | "Layer already exists" 오류 | 처음 한 번 추가, 이후 `setData` |
| 위치 권한을 화면 열자마자 요청 | 사용자가 거부하고 다시 안 물음 | 버튼을 눌렀을 때만 |
| 같은 와이파이 IP 로 휴대폰 시험 | 위치 권한을 묻지도 않음 | HTTPS 터널 (cloudflared) |
| 대체 지도로 바꾼 뒤 경로가 사라짐 | 우리 레이어가 스타일과 함께 지워짐 | 바꾼 뒤 그리기 함수 다시 호출 |
