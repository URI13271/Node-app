# 시드 데이터

지역마다 폴더 하나를 둔다 (예: `gnu-gajwa/`). 뼈대에는 데이터가 없다.

| 파일 | 내용 |
|---|---|
| `places.json` | 장소 |
| `buildings.geojson` | 건물 바닥, 높이 |
| `entrances.geojson` | 입구 |
| `parking_lots.geojson` | 주차장 |
| `landmarks.geojson` | 랜드마크 |
| `walk_routes.geojson` | 도보 경로 선 |
| `walk_route_steps.json` | 단계 문장, 지점, 카메라 |
| `osm/walk_network.json`, `osm/buildings_osm.json`, `osm/manual_crossings.json` | 경로 생성용 원본 |
